## JavaScript Mini Projects 🎮

This repository contains two fun and interactive mini projects built using JavaScript, HTML, and CSS.

📌 Projects Included
1. Stone Paper Scissors ✊📄✂️

A simple game where users can play Stone Paper Scissors against the computer with real-time result display and score tracking.

2. Tic Tac Toe ❌⭕

A classic two-player Tic Tac Toe game with winner detection and restart functionality.

🚀 Features
- Interactive UI
- Beginner-friendly JavaScript projects
- Responsive design
- Game logic implementation using JavaScript

  
🛠️ Tech Stack
- HTML
- CSS
- JavaScript
